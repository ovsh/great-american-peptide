## What we extracted from the images

The PRD docs reflect:
- 14 unique screens across both mocks
- Cream / navy / red palette with editorial serif headings
- Three-stars motif on the masthead, wax-seal in the bottom nav
- Card-driven dashboards with eyebrow → hero number → caption → chart pattern
- Bottom nav: Home / Calendar / [Seal] / History / Profile
- Multi-med UX: due-today list, color-coded medications, body-site picker with front/back toggle
- Status pills: Healthy (green), Connected (green), Due today (red), On time (green), Tomorrow (gray), Scheduled (gray)
