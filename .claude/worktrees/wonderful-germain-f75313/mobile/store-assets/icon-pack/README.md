## Generation Prompt

Create a premium app icon for a peptide medication tracker that matches an American heritage clinical design system. Use a warm parchment background, deep navy ink, crimson accents, and metallic gold. Center a wax-seal style circular medallion with a clean peptide vial silhouette, three small five-point stars above, and subtle red stripe bands below. Include a gold rim and navy linework. Use no readable text, letters, labels, needles, syringe, people, pills, QR codes, watermarks, or literal flag fabric. Keep the mark simple, high contrast, centered, and legible at small sizes with generous safe padding for rounded app icon masks.
